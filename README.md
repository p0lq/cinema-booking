# Cinema Booking

Практическая работа №3. Мобильное приложение для бронирования билетов в кинотеатр на Flutter / Dart.

## Запуск

```
flutter pub get
flutter run
```

Тесты: `flutter test`.

На Windows путь к проекту с кириллицей (например, `C:\Users\Фвьшт\...`) ломает `flutter analyze`. Обход: подключить папку как диск (`subst P: "C:\Users\Фвьшт\college"`) и запускать команды из `P:\cinema_booking`.

## Структура

- `lib/models` – модели `Movie`, `Session`, `Booking`, схема зала `HallLayout` (8 рядов × 10 мест, A1–H10).
- `lib/services` – расчёт цены и промокодов (`pricing.dart`), загрузка каталога (`movie_repository.dart`), локальное хранилище на shared_preferences (`storage_service.dart`).
- `lib/state` – `BookingProvider` (фильмы, занятые места по сеансам, брони, отмена) и `ThemeProvider`.
- `lib/screens` – 8 экранов: Home, Movie Details, Sessions, Seat Selection, Checkout, E-Ticket, Booking History, Booking Details.
- `lib/widgets` – карточки фильмов, место в зале, сводка стоимости, статус брони.
- `assets/data/movies.json` – каталог из 13 фильмов (12 с сеансами, «Тени империи» без сеансов для проверки пустого расписания).

## Логика

Цены: ряды A–F стандарт 2500 ₸, G–H VIP 4000 ₸. Промокоды: CINEMA10 (10%), MOVIE20 (20% от 4 билетов). Итог = сумма цен мест − скидка.

Занятые места хранятся отдельно для каждого сеанса (ключ `m03_20261021_1600`). При первом открытии сеанса часть мест помечается занятыми, имитируя других зрителей. Перед созданием брони места проверяются ещё раз, повторно занять место нельзя. Отмена переводит бронь в статус «Отменённое» и освобождает места. Активная бронь на прошедший сеанс показывается как «Завершённое».

Оплата картой учебная: диалог с имитацией обработки, банковские данные не запрашиваются.

## Дополнительные функции

- Светлая и тёмная тема (переключатель на главном экране, выбор сохраняется).
- Анимация выбора мест (масштаб и смена цвета).
- Фильтрация по жанру, рейтингу и продолжительности.
